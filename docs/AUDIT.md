## Resolution of the open decisions (2026-10-10)

The owner accepted the recommended options:

- **S1.6 storage:** SQLite/Drizzle, as the spec says. SQLite is an embedded file, so no database
  server is involved. The half-done JSON port was dropped, and the pre-port Drizzle code was rebuilt
  by replaying the recorded edits onto `d0726ff`; every file the port did not touch matched
  byte-for-byte. A copy of the JSON port is kept outside the repo.
- **S3.x Twilio:** kept. It stays inert unless its variables are set.
- **CI/Docker:** GitHub Actions runs CI, including the Docker build. Locally, `verify` reports the
  Docker check as SKIPPED when Docker is not installed and never as PASS.

After the rebuild (before Phase 1 changes): typecheck PASS, tests 255/255 PASS, build PASS, lint PASS.
That needed two fixes:

- Backup snapshots are now made standalone (no `-wal`/`-shm` side files).
- A backup test that slept 50 ms now awaits the catch-up run instead.
